Invoices

In development

Standalone billing for servers that want invoicing without the full Banking economy: issue an invoice, get paid, chase what is open. It is being split out of Banking as its own resource and it is not finished.

€25 Estimated price, not final. No Tebex package yet and no release date announced. Not purchasable yet

What is planned.

Invoices takes the billing part of Banking and ships it on its own, so a server that only needs mechanics billing customers does not have to run accounts, markets and payroll to get it. Like every VAmore script, its settings will register into Config Manager.

Nothing beyond that is decided. There is no feature list to promise, no screenshots to show, and no date. This page changes when that changes.
