Description

Standalone billing for servers that want invoicing without the full Banking economy: issue an invoice, get paid, chase what is open. It is being split out of Banking as its own resource and it is not finished.

What is decided
  • It ships as its own resource, not as a Banking add-on.
  • Its settings register into Config Manager like every other VAmore product.
  • ESX, QBCore and Qbox in one build.
What is not decided

The feature list, the final price and the release date. There are no screenshots to show and no date to promise. This page changes when that changes.

Banking already invoices today.

Invoices takes the billing part of Banking and ships it on its own, so a server that only needs mechanics billing customers does not have to run accounts, markets and payroll to get it. If you need invoicing now, Banking is the resource that has it.
