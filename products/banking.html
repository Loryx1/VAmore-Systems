Banking

[ running ]

A complete, standalone banking and economy resource: accounts and transfers, savings and credit, live stock and crypto markets, faction payroll, and a fraud-detection dashboard. One resource, no framework-specific forks.

€40 one-time, per server · ESX · QBCore · Qbox · configured through Config Manager

What is in it.

vamore_banking — 6 modules
  • core bankingAutomatic IBAN accounts, 4-digit PIN protection, ATM and branch deposits and withdrawals, IBAN-only transfers with contacts, and a fully filterable statement.
  • savings + creditTiered compounding savings interest with trackable goals, plus an event-based credit score with score-tiered loan limits and interest.
  • markets10 stocks and 5 coins on live, server-driven pricing engines, with price history charts and take-profit / stop-loss orders.
  • faction accountsJob-bound accounts with grade-gated access, automatic per-grade salary payouts, and a full accounting ledger, with no manual member management.
  • fraud dashboardFlagged high-value transactions, a suspicious-activity filter, Discord webhook alerts, per-player rate limiting, and configurable daily caps.
  • configurationEvery setting (PIN lockouts, daily limits, which modules run at all) is controlled live through Config Manager. No restarts, no config.lua.

Before you buy.

Banking runs on its own. Config Manager is free and optional: install it and every Banking setting moves into an in-game panel instead of a file you have to edit and reload.
